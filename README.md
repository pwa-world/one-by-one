# 云海邮局

温暖绘本风的二合一合成游戏。你经营一座漂浮在云海里的旧邮局，为空岛居民制作物品、投递包裹，慢慢修复断开的航线。

原生 HTML、CSS、JavaScript，无框架、无构建步骤、无运行时第三方依赖。所有图形为本地 SVG，音效由 Web Audio 合成；完整静态资源体积约 130 KB。游戏逻辑无需服务器或账号。

## 启动

安装 Node.js 20 或更新版本，然后在此目录运行：

```sh
node server.mjs
```

打开 http://localhost:4173 。也可以运行 `npm start`（如果本机安装了 npm）。

不要直接双击 HTML 文件：ES Modules 和 Service Worker 需要 HTTP 本地服务或 HTTPS。`server.mjs` 只监听本机，适合桌面开发预览。手机安装请使用 HTTPS 静态部署地址。

## 已实现内容

- 7 × 8 工作台，6 个固定生成器，50 个可周转物品格。
- 6 个岛屿章节，18 项建设，每章有居民来信与独立剧情，主线有完整结尾。
- 6 类生成器、12 条合成链、84 种有名字的物品，最高 7 级。
- 所有普通生产无体力、无冷却。每种生成器有两类产出，主产出 74%、副产出 26%。
- 3 档持续刷新的居民委托、免费换单、每 5 单的街坊谢礼。
- 生成器 4 级成长、8–32 格仓库、物品回收、整理、图鉴、10 项成就。
- 拖动合成、点选合成、物品交换、键盘操作；最多撤销 20 次操作，资源与物品一起回退。
- 手机委托横向滚动、独立航线页、底部导航、安全区域适配、音效开关和减少动态效果。
- 本机自动存档、上一份有效备份、JSON 导入导出、损坏校验、跨窗口写入冲突保护。
- PWA manifest、Service Worker、192/512 PNG 图标、所有游戏资源离线预缓存。

## 操作

1. 点击绿色生成器生成物品。
2. 把两个同种同级物品拖到一起，或依次点选两者，合成高一级物品。
3. 按居民要求准备物品，寄出包裹获得邮票。
4. 用邮票和建设材料修复设施；每 3 项建设开启下一章。
5. 棋盘满时可以交单、合成、存入仓库，或回收闲置物品获得升级零件。

订单需要准确等级，高一级物品不能直接代替。仓库物品可以直接参与交单和建设。所有随机订单只使用已经解锁的合成链。完成主线后仍可继续订单和收藏。

## 离线与存档

首次联网打开，等页脚出现“离线已就绪”，再离线使用。支持通过浏览器安装到主屏幕；iOS 使用 Safari 的“分享 → 添加到主屏幕”。首次下载需要网络，之后游戏本身不调用网络接口。

进度写入当前浏览器、当前站点的 `localStorage`。操作后约 280ms 保存，连续操作时最迟约 1.8 秒保存，页面隐藏时立即保存。存档带版本号和校验和；每次成功保存保留上一份有效数据。损坏时尝试恢复备份，双份损坏时保留原始数据并提供恢复界面。另一个窗口更新存档后，旧窗口停止写入，避免静默覆盖。

不同设备、不同浏览器、不同站点地址的存档互不相通，请通过导出/导入迁移。浏览器隐私模式、主动清理网站数据或系统回收站点存储仍可能导致本机数据丢失，重要进度请导出保管。存档中的校验和用于检测损坏，不是防作弊机制。

## 部署与更新

把 `dist/` 原样放到支持 HTTPS 的任意静态服务器即可，支持子目录部署。无需 API、数据库、在线字体或 CDN。

修改文件后务必同时更新 `dist/sw.js` 的缓存版本字符串，让设备完整下载新版本。离线导航优先使用已缓存的完整应用；新缓存安装成功后才接管。

### GitHub Pages

目标仓库：<https://github.com/pwa-world/one-by-one>。

工作流 `.github/workflows/pages.yml` 在推送到 `main` 或 `master` 时运行，也支持手动运行。它先运行游戏规则、存档和离线检查，再将 `dist/` 发布到 GitHub Pages。仓库的 **Settings → Pages → Build and deployment → Source** 需要设为 **GitHub Actions**。

默认项目站点地址为 <https://pwa-world.github.io/one-by-one/>，以仓库 Pages 设置返回的实际地址为准。所有资源均使用相对路径，支持 `/one-by-one/` 子路径；游戏本身不需要登录。

## 文件结构

- `dist/data.js`：合成链、生成器、章节、建设、居民与成就内容。
- `dist/engine.js`：纯游戏规则、状态验证、存档序列化。
- `dist/art.js`：绘本风物品、角色、岛屿 SVG 插画。
- `dist/app.js`：界面、指针交互、音效、存档和安装体验。
- `dist/style.css`：桌面及手机布局、动画和无障碍样式。
- `dist/sw.js`：离线资源缓存。
- `server.mjs`：本地静态服务器。
- `tests/`：规则、章节可达性、长时间操作、存档与离线策略检查。

## 检查

```sh
node --test tests/*.test.mjs
```

检查包括 18 个建设阶段所需材料的可达性、重复材料消费、仓库容量、无体力连续生产、1 万次操作状态完整性、存档恢复与离线资源请求。真实浏览器的视觉布局、手势、系统安装和实际断网重开还需要在目标设备验证。

图标 PNG 已随项目提供。`make-icons.ps1` 仅用于在 Windows 上重新生成图标，正常游玩无需执行。
